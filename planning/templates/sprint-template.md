# Sprint Plan Template

## Sprint objective
One sentence objective tied to outcome impact.

## Capacity assumptions
State total capacity, commit level, reserve.

## In-scope
List deliverables and major tickets.

## Out-of-scope
List explicit exclusions.

## Deliverables by component (linked to outcomes)
Map component -> DEL -> OUT.

## Cross-component dependencies
List only blocking dependencies.

## Risks + fallback scope cuts
List risks and what to cut first.

## Demo script
Step-by-step demo flow.

## Exit criteria
Objective checks required to close sprint.
