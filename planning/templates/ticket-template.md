# Ticket Template

## Summary
Short implementation statement.

## User value
Who benefits and how.

## Technical scope
Concrete implementation boundaries.

## Acceptance criteria (Given/When/Then)
- **Given** initial state
- **When** action occurs
- **Then** expected result

## Dependencies
Required upstream/downstream inputs.

## Test notes
Manual or automated checks to run.

## Rollout/rollback notes
- Rollout steps
- Rollback steps

## Labels
Priority, component, outcome, sprint.

## Estimate
Points estimate.

## Owner
Single accountable owner.
